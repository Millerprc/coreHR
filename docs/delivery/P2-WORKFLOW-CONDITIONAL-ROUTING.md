# P2 条件流程路由交付回执

> 交付日期：2026-08-11
> 状态：`PASS`
> 范围：第二阶段流程引擎的安全条件分支与主管理员配置入口

## 1. 已交付

- 流程连线可以配置结构化条件组，支持 `all/any`。
- 单组最多20条规则，字段路径最多8级。
- 支持等于、不等于、大小比较、属于/不属于列表、字段存在/不存在。
- 只读取流程实例 `context`，不执行Python、JavaScript、SQL或任意文本表达式。
- 条件命中唯一分支时自动推进；没有命中时可走唯一默认连线。
- 多条分支同时命中、没有命中且无默认、持久化配置损坏时全部拒绝推进。
- 旧的无条件多分支仍可使用显式 `route_targets`，不改变已有流程行为。
- 实际选路以 `source/target/strategy` 写入实例 `_workflow_route_history`，可回看条件、默认、单线或显式选路结果。
- 主管理员页面提供“统一审批/按条件分流”选择、判断字段、判断方式、值类型、比较值和两组办理角色，不需要手写JSON。

## 2. 安全边界

- 缺失字段不会被当作普通比较成功；必须显式使用“字段不存在”。
- 数字和文本不会隐式互转；类型不一致时条件不成立。
- `not_in` 在没有同类型候选值时也不会放行。
- 同一来源节点不允许重复条件；条件分支最多一条默认线。
- 多条件同时命中不按配置顺序抢先选择，必须修正规则后重试。

## 3. 验证

- PostgreSQL集成测试证明条件命中和默认分支会创建不同审批任务，并记录选路历史。
- 管理端构建器覆盖数字比较、列表比较和无效数字拦截。
