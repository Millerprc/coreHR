# 第一阶段数据治理导入导出交付回执

> 日期：2026-08-09
>
> 范围：主管理员使用的非敏感主数据初始化与当前有效快照导出
>
> 状态：`IMPLEMENTED_AND_VERIFIED`

## 1. 已交付

- 六类主数据：数据字典、字典项、组织类型、法人主体、职务、组织首个有效版本。
- 管理端 CSV 模板下载、文件本地解析、列白名单和批次预校验。
- 服务端严格字段校验、逐行拒绝原因、父子字典关系及循环检查。
- 校验与执行分离；执行必须填写原因。
- 来源系统、来源表、来源记录 ID、内容校验和及目标记录追踪。
- 幂等键保护；同来源同内容跳过，同来源内容变化时拒绝并等待更新策略。
- 组织初始化保留历史编码，按父级依赖排序，校验组织类型、父级有效期和循环，并生成组织创建事件及下游事件。
- 数据治理查看/管理权限、批次列表和明细、执行审计。
- 六类主数据按配置的业务时区导出当天有效快照；组织只导出当天有效的版本和上级编码。
- 导出 CSV 使用 UTF-8 BOM，包含稳定来源标识，并对可能触发表格公式的单元格做安全处理。

## 2. 安全边界

- 单批最多 1000 行，单行最多 20 个字段、10000 个 JSON 字符。
- 模板外字段由浏览器和服务端双重拒绝。
- 无效行不保存原始未知字段，避免误存人员联系方式等敏感内容。
- 当前入口不接收人员、证件、薪酬、联系方式或附件；组织多版本历史仍不在本批范围。
- 单次导出最多 50000 行；导出审计只记录类型、业务日期和行数，不在审计日志复制主数据正文。
- 本轮验证仅使用合成数据；未读取、上传或复制企业真实人员数据。

- TypeScript 严格检查和 Vite 正式构建通过。
- PostgreSQL 空库升级、迁移回退、重新升级和 Alembic 模型差异检查通过。

- 浏览器登录、9 个菜单、“数据治理”工作区、导入/导出表单和未知列拒绝路径通过。
