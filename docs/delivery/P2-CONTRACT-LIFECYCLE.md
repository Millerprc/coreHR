# 第二阶段合同/协议生命周期交付回执

> 日期：2026-08-09
>
> 范围：主管理员使用的合同/协议建档、变更、续签、解除、取消、到期提醒和回退
>
> 状态：`IMPLEMENTED_AND_VERIFIED`

## 1. 已交付

- 合同/协议关联 Person，并且只能在劳动关系和协议关系中选择一种；关联关系必须属于同一 Person。
- 保存合同类型、编号、法人主体、签署日、生效/结束日、提前提醒天数、状态、版本和扩展备注。
- 支持变更、续签、解除和取消；直接模式免审批，未来日期仍按生效日进入待执行队列。
- 续签生成新的合同记录，并保存前序合同 ID；原合同标记为已续签。
- 回退形成新的事件记录：普通动作恢复前值，续签回退恢复原合同并取消后继合同。
- 管理端展示到期提醒、状态和版本，并提供到期状态刷新及生命周期动作入口。

## 2. 一致性、并发与审计

- 所有合同动作复用统一人事事件引擎，不另建平行流程；直接、未来、审批和回退语义保持一致。
- 创建动作和回退均可使用 UUID 幂等键；同一内容重试返回同一事件，不重复变更或续签。
- 同一幂等键用于不同内容时返回冲突。
- 已连续生效多个动作时必须按执行顺序逆序回退；系统拒绝用旧动作回退覆盖后续有效结果。
- 合同创建、管理员更正、动作执行、续签新建、到期处理和回退均写入审计日志。
- 审计保存操作人、原因、Trace ID、前值、后值；合同本身保存递增版本。
- 到期提醒同时受查询窗口和合同自身“提前提醒天数”约束。

## 3. 明确边界

- 企业正式合同类型、完整字段、默认提醒节点和自动通知对象仍需按[企业输入包 02](../input-packs/02-contract-agreement-fields-and-attachments.md)确认。
- 当前审批能力使用通用流程引擎；真实合同审批节点、会签/或签、处理人和条件需企业流程图。
- 文件存储、病毒扫描、加密、水印、保留年限和电子签章尚未确认，因此本次不包含附件归档。
- 到期状态当前提供管理员/调度调用能力；正式自动运行时点与失败通知需部署规则确认。
- 本次测试只使用本机 Docker 和合成数据，未写入或上传企业真实数据。
