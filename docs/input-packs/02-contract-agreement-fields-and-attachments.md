# 企业输入包 02：合同/协议正式字段与附件规则

> 状态：`WAITING_FOR_BUSINESS_CONFIRMATION`
>
> 适用阶段：第二阶段企业适配
>
> 数据安全：只填写字段定义、枚举、期限和规则；不要在本文件中填写人员姓名、证件号码、合同原文或其他真实个人数据

## 1. 当前系统已经具备什么

主管理员目前可以：

- 将合同/协议关联到 Person，并且二选一关联劳动关系或协议关系。
- 保存合同类型、编号、法人主体、签署日期、生效/结束日期、提前提醒天数和扩展备注。
- 执行变更、续签、解除和取消；未来生效动作进入人事事件待执行队列。
- 查看续签前后合同链路、状态和版本；对已生效动作创建新的回退事件。
- 使用幂等键防止重复提交，并在审计中追踪操作人、原因、Trace ID 和前后值。
- 查看未来 90 天内、且已经进入各合同自身提醒期的到期提醒。

这些是通用产品能力。以下企业输入用于决定正式字段、业务校验和附件治理，不影响当前通用闭环继续试用。

## 7. 最小提交顺序

1. 先确认表 A 的类型代码和表 C 的期限/状态规则。
2. 再提供表 B 的正式字段表头，不需要真实数据行。
3. 再确认表 D 各动作是否审批及其流程图。
4. 最后确认表 E 的存储、安全、保留和电子签章规则。

收到第 1–2 项后即可收口合同表单和导入模板；收到第 3 项后可替换通用审批；收到第 4 项后再开发附件能力。
