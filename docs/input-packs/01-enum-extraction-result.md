## 3. 明确禁止的错误映射

1. 不得把 `nationality_id/nationality=1/汉族` 写入 `persons.nationality_code`。
2. 不得根据唯一的 `department_level=2` 猜测组织类型。
3. 不得把 `ehr_employee_part_dept.status=已结束` 当作兼岗、借调或虚线关系类型。
4. 不得把单行样例当成企业全部枚举并直接导入正式库。
