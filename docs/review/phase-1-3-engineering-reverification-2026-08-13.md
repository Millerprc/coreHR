## 3. 数据隔离

复验脚本使用进程级独立数据库 `corehr_test_<PID>`，只执行合成测试数据。结束时使用强制断开连接方式删除该临时库。

本次没有：

- 查询或修改现有 `corehr` 业务数据库；
- 读取 `ehr_data.sql`、旧 EHR 表样例或人员敏感数据；
- 上传测试数据、数据库内容或本机文件到外部服务；
- 删除 PostgreSQL 数据卷。

复验后只保留 PostgreSQL 和 Redis 依赖容器处于健康运行状态，便于继续本机开发；API 和 Web 业务容器没有被启动。

这些提示没有造成测试或构建失败，但应在进入生产化专项前关闭。
