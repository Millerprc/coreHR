## 2. 功能实现情况

- 管理员可以在“数据治理”选择“组织历史版本”、下载模板、上传CSV、预校验和执行。
- 同组织多版本可以乱序出现在文件中，执行时自动按生效日期排序。
- 批内父子版本按目标日期建立依赖；无法解析的依赖会停止执行并要求重新校验。
- 过去或当天版本生效后，上一版本结束日自动调整为新版本生效日前一天。
- 未来版本不会提前写成实际版本，而是保留计划状态。
- 相同来源记录和相同内容再次提交会跳过，不会重复产生组织事件。
- 历史任务不会出现在“导出当前主数据”选择中，避免把事件误当当前快照。
