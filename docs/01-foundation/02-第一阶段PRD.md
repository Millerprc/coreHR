# HRIS 第一阶段产品需求文档

> 状态：PRD骨架草案  
> 版本：v0.1-draft  
> 当前读者：用户、产品分析、后续开发任务拆解者

## 1. 产品目标

为 HR 系统管理员和SSC提供统一的组织与人员基础数据平台，替代现有系统中第一阶段范围内的基础数据维护能力，并为后续流程、考勤和薪酬提供可信主数据。

## 2. 第一阶段用户

| 用户 | 目标 | 状态 |
|---|---|---|
| 系统管理员 | 配置系统、账号、角色、字典和高风险权限 | `CONFIRMED` |
| SSC管理员 | 初始化和维护组织、人事、编制、招聘需求数据 | `CONFIRMED` |
| 只读审计员 | 第一阶段不预置，后续通过自定义角色能力配置 | `DEFERRED` |
| 业务负责人 | 查看下级组织及人员数据 | `DEFERRED` |
| 员工本人 | 自助查看和修改资料 | `DEFERRED` |

## 3. 信息架构

建议一级导航：

```text

  └─ 收入目标

  ├─ 职务体系
```

## 4. 页面与功能

### 4.1 登录

目标：使用本地账号密码进入系统。

要求：

- 首次初始化由部署过程创建管理员，但不得使用固定生产密码。
- 登录失败不暴露账号是否存在。
- 支持账号停用。
- 企业微信登录推迟到后续阶段。

### 4.2 工作台

第一阶段建议展示：

- 当前有效组织数量。
- 法人数量。
- 当前人员数量及人员类型分布。
- 待入职人数。
- 本月编制数、当前人数和差额。
- 最近导入批次及失败记录。
- 最近高风险操作。

指标口径未确认的卡片不得上线。

### 4.3 当前组织树

用户可以：

- 按名称和编码搜索组织。
- 展开和收起组织层级。
- 查看组织类型、负责人、法人、成本中心、收入目标和人员结果。
- 进入组织详情。
- 在组织详情中按生效日期查看当前、历史和待生效的版本、事件及快照信息。
- 不生成未来组织树，也不建设独立的待生效组织事件页面。
- 仅查看当前有效组织树。

验收示例：

1. 某BU下存在多个部门。
2. 同一BU关联多个法人。
3. 同一组织分摊至多个成本中心且比例合计100%。
4. 组织未来换上级时，生效前组织树保持不变。
5. 到达生效日后组织树自动体现新关系。

### 4.4 组织维护

用户可以：

- 新建组织并自动生成流水编码。
- 导入历史组织及历史编码。
- 修改名称和类型。
- 预约换上级、合并、拆分、撤销。
- 维护最多三名负责人。
- 查询变更历史。

规则：

- 第一阶段普通组织变更采用直接或未来生效，不建设通用审批流程。
- 已生效事件通过受控回退处理，不直接删除或取消历史。
- 回退按场景配置为直接生效或审批生效，完整流程引擎在第二阶段衔接。

### 4.5 法人主体

用户可以：

- 维护法人主体档案。
- 维护法人和组织的多对多关系。
- 为关系设置生效和失效日期。
- 查询某法人覆盖的组织及人员。
- 查询某组织关联的所有法人。

具体主体字段以后续真实表结构为准。

### 4.6 成本中心

用户可以：

- 维护成本中心。
- 为组织配置一个或多个成本中心及比例。
- 校验同一有效区间比例合计100%。
- 创建新版本并指定未来生效日期。
- 查看历史版本。

### 4.7 收入目标

用户可以：

- 在叶子组织维护年度和月度收入目标。
- 选择币种。
- 调整目标并创建新版本。
- 查看上级组织按币种汇总的结果。
- 查看目标历史快照。

限制：

- 上级非叶子组织不能直接编辑汇总值。
- 不换算不同币种。
- 不管理实际收入。

### 4.8 职务体系

目标：

- 维护职务。
- 展示职务、职级、职等、职类、序列关系。
- 支持初始化导入。
- 为组织职务和编制提供基础数据。

字段和层级等待现有职位表结构后补充。

### 4.9 月度编制

用户可以：

- 选择年月查看所有组织+职务的编制数据。
- 新增或修改指定年月的编制数。
- 查看月初、月末、月均和当前人数。
- 查看编制差额。
- 导入和导出月度编制。
- 查看历史版本和修改日志。

限制：

- 不限制招聘需求。
- 不预留空编。
- 不阻止超编。
- 不将12个月人数相加作为年度编制。

### 4.10 月度快照

用户可以：

- 查看月初和月末快照任务。
- 查看快照是否成功。
- 查看每批快照的数据范围和记录数量。
- 使用授权权限补跑或修订。
- 对比两个快照版本。

快照规则：

- 系统按快照策略配置的时区自动生成月初和月末快照。
- 每批记录所用时区、月份边界时刻和规则版本。
- 用户不得直接修改快照记录。
- 发现错误时先更正源业务数据。
- 授权用户生成与原版本关联的修订版本。
- 修订版本重新冻结，原始版本永久保留。

### 4.11 招聘需求

用户可以：

- 创建招聘需求。
- 选择组织和职务。
- 填写需求人数、期望日期、原因和说明。
- 查看相关月度编制和人员结果。
- 推进需求状态。
- 关闭或取消需求。

限制：

- 编制信息只作参考。
- 系统不因无空编、超编或业务冻结自动阻断。
- 不包含候选人、面试、Offer和录用。

### 4.12 人员档案

用户可以：

- 创建自然人档案。
- 创建待入职雇佣记录并分配六位工号。
- 维护计划入职日期。
- 维护主组织、职务及四类主体。
- 查询自然人的历史雇佣记录。
- 二次入职时匹配原自然人并恢复原工号。
- 查看字段变更历史。

待补充：

- 完整档案字段。
- 多国证件规则。
- 合作、劳务派遣等协议关系的真实字段和协议类型字典。

### 4.13 导入

初始化导入流程：

```text
下载模板
→ 上传文件
→ 整批校验
→ 展示错误
→ 用户修正并重传
→ 整批入库
→ 生成导入批次与审计记录
```

日常批量维护允许部分成功，并提供失败明细。

### 4.14 审计日志

至少支持查询：

- 数据新增、修改和停用。
- 修改前后内容。
- 导入与导出。
- 月结解冻。
- 敏感字段明文访问。
- 快照生成和修订。
- 登录失败和账号停用。

## 5. 状态机

### 5.1 组织事件

建议状态：

```text
草稿 → 待生效 → 已生效
  └→ 已取消
```

已生效组织事件按场景进入回退路径：

```text
回退申请 ──直接生效策略──→ 回退处理中 → 已回退/回退失败
        └─审批生效策略──→ 回退审批中 → 已通过 → 回退处理中
                                      ├→ 已驳回
                                      └→ 已撤回
```

回退审批是受控领域动作，不等同于第一阶段建设通用流程引擎。

### 5.2 招聘需求

第一阶段启用路径：

```text
草稿 → 已通过 → 招聘中 → 已完成
草稿/已通过/招聘中 → 已取消
```

`审批中`、`已驳回`和`已撤回`保留为状态代码，但第一阶段不生成审批实例。第二阶段接入流程引擎后启用审批路径。

### 5.3 雇佣状态

第一阶段至少支持：

- 待入职
- 试用
- 在职
- 停薪留职
- 离职中
- 已离职

状态转换规则主要属于第二阶段，第一阶段只维护当前结果和历史。

## 6. 关键验收旅程

### UAT-01 企业基础数据初始化

1. 下载组织、法人、成本中心和职务模板。
2. 导入含历史编码的数据。
3. 系统整批校验并指出错误。
4. 修正后重新导入。
5. 当前组织树和主体关系正确展示。
6. 导入批次和审计记录可追溯。

### UAT-02 组织未来变更

1. 管理员创建未来换上级事件。
2. 生效日前当前组织树不变。
3. 在目标组织详情中可以按生效日期查询该事件及计划版本。
4. 生效日系统应用新上级。
5. 组织历史和审计记录完整。

### UAT-03 成本中心版本

1. 组织当前按60%/40%分摊。
2. 创建未来70%/30%版本。
3. 系统校验比例必须为100%。
4. 生效日前后查询得到对应版本。
5. 月末快照保留当时版本。

### UAT-04 二次入职

1. 使用证件搜索到历史自然人。
2. SSC确认属于同一人。
3. 创建新的雇佣记录。
4. 系统恢复原六位工号。
5. 前后两次雇佣经历分别可查。
6. 同一自然人的重叠法人劳动关系被拒绝，新增合作或劳务派遣协议关系不受该唯一性限制。

### UAT-05 编制结果

1. 选择年月导入组织+职务编制。
2. 系统展示月初、月末、月均和当前人数。
3. 超编只显示结果，不阻止招聘需求。
4. 导出结果与页面口径一致。

- 真实表结构尚未提供的字段级设计。
- 未提供真实流程图的通用审批链和第二阶段流程配置。
- 生产SLA、备份和灾备参数。
- 万人并发的具体响应时间和吞吐指标。
