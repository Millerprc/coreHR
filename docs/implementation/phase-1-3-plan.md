# 业务一至三阶段实施计划

> 状态：`IMPLEMENTED_AWAITING_BUSINESS_UAT`
> 日期：2026-08-09
> 执行分支：`main`（用户明确授权）

## 1. 实施授权与约束

用户已明确授权在尚未提供企业现有数据库表结构的情况下，直接启动业务第一至第三阶段开发。

当前实现遵守以下约束：

- 使用当前已确认的需求、决策和领域规范设计第一版内部数据模型。
- 后续收到现有系统表头、字段和脱敏样例后，通过版本化迁移和导入映射适配，不覆盖历史迁移。
- 未提供的审批流程图、考勤细则和国家本地化规则不得被猜测为正式规则。
- 未确认规则先以可配置结构、明确状态或待验收项承载，不伪造“已完成”业务能力。
- 第一至第四阶段仍以PostgreSQL为唯一运行数据库；MySQL和Oracle支持延后到第五阶段。

## 3. 每批完成定义

每个批次必须同时具备：

1. 数据库迁移。
2. 领域模型和服务端校验。
3. 版本化REST API和OpenAPI契约。
4. 管理端可操作入口。
5. 正常、边界、失败和权限测试。
6. Docker复跑和清理脚本。
7. 交付回执、已知限制和下一批输入清单。
