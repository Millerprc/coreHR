## 1. 使用规则

- 本目录文档只用于追溯项目起点、旧阶段页面设计、历史架构选择和既有开发任务。
- 文档中的已确认业务事实不会因归档而失效，但必须以[项目决策](../../01-foundation/03-项目决策.md)或新的模块功能需求文档为正式载体。
- 本目录中的`PARTIAL`、`COMPLETED`或`DEFERRED`只描述当时状态，不代表当前产品状态。
- 新开发以[正式文档目录](../../01-foundation/00-正式文档目录.md)、[产品总体PRD](../../01-foundation/16-coreHR产品总体PRD.md)和[模块功能需求文档规范](../../01-foundation/17-模块功能需求文档规范.md)为准。
